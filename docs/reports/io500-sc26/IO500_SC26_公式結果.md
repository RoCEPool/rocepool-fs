# IO500 SC26：正式結果

RoCEPool の IO500 SC26 リストへの提出は IO500 に受理され、公開されました。

| | |
|---|---|
| **IO500 スコア** | **102.30** |
| 帯域スコア | 12.29 GiB/s |
| メタデータスコア | 851.18 kIOP/s |
| 順位 | SC26 Research リスト 162 件中 101 位 |
| クライアントノード／プロセス | クライアント 6 ノード、各 32 プロセス（合計 192） |
| 提出日 | 2026 年 11 月 3 日（実行は 2026 年 11 月 2 日） |
| 公式ページ | [https://io500.org/submissions/view/819](https://io500.org/submissions/view/819) |

## フェーズ別の結果

| フェーズ | 結果 | 単位 |
|---|---:|---|
| ior-easy-write | 16.44 | GiB/s |
| ior-easy-read | 26.87 | GiB/s |
| ior-hard-write | 3.56 | GiB/s |
| ior-hard-read | 14.54 | GiB/s |
| mdtest-easy-write | 730.66 | kIOP/s |
| mdtest-easy-stat | 969.38 | kIOP/s |
| mdtest-easy-delete | 747.96 | kIOP/s |
| mdtest-hard-write | 267.96 | kIOP/s |
| mdtest-hard-read | 889.31 | kIOP/s |
| mdtest-hard-stat | 982.08 | kIOP/s |
| mdtest-hard-delete | 682.54 | kIOP/s |
| find | 3,256.07 | kIOP/s |
| ior-rnd4K-easy-read | 2.06 | GiB/s |

スコアの算出：帯域は IOR 4 フェーズの幾何平均、メタデータは mdtest と find の 8 フェーズの幾何平均、IO500 スコアは √(帯域 × メタデータ) です。4 KiB ランダム読み取りは IO500 が実験的と位置づけており、スコアには含まれません。
